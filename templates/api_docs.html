REST API

All endpoints return JSON. Base URL: {{ request.url_root }}api

Authentication & limits

Read endpoints are open. Write endpoints (POST /api/book, POST /api/book-round-trip, POST /api/cancel/<pnr>, POST /api/reschedule/<pnr>) require an API token in the X-API-Token header.

Demo token: demo-token-123. Requests are limited to 60 per minute per token.

OpenAPI 3.0 spec ({{ spec_url }})

GET /api/stations?q=del

Search the station master by city, name or code.

{"stations": [{"code": "NDLS", "name": "New Delhi", "city": "Delhi"}]}

GET /api/trains

List every seeded train with its number and name.

{"trains": [{"id": 1, "train_number": "12951", "train_name": "Mumbai Rajdhani Express"}]}

GET /api/search?from=Mumbai&to=Delhi

Find trains between two cities with live distance and duration.

{"count": 1, "results": [{"train_number": "12951", "distance_km": 1386, "duration": "15h 35m"}]}

GET /api/availability

Query parameters: train_id, cls, date, from_seq, to_seq and optional quota.

{"available": 72, "fare_per_passenger": 785, "tatkal_open": false}

GET /api/seatmap

Coach-wise seat map for a leg. Same query parameters as /api/availability.

{"coaches": [{"name": "S1", "seats": [{"seat_number": 1, "berth_type": "LB", "status": "available"}]}]}

POST /api/book

Creates a booking and returns a PNR. If no seats are free the passenger is added to RAC or the waitlist. Requires a token.

{
  "train_id": 1, "class": "SL", "date": "2026-11-10",
  "from_seq": 1, "to_seq": 4, "quota": "GN",
  "user": {"name": "Aarav", "email": "aarav@example.com", "phone": "9876543210"},
  "passengers": [{"name": "Aarav", "age": 34, "gender": "M", "preference": "LB"}]
}

Response: {"pnr": "4021887731", "status": "confirmed"}

POST /api/book-round-trip

Books an outbound and a return leg together; the return leg gets a 5% discount. Requires a token.

{
  "user": {"name": "Aarav", "email": "aarav@example.com"},
  "outbound": {"train_id": 1, "class": "SL", "date": "2026-11-10", "from_seq": 1, "to_seq": 4},
  "return": {"train_id": 2, "class": "SL", "date": "2026-11-14", "from_seq": 1, "to_seq": 4}
}

Response: {"group_id": "...", "outbound": "4021887731", "return": "7712339880"}

GET /api/pnr/<pnr>

Full booking record with passengers, payments, refunds and reschedule history.

POST /api/cancel/<pnr>

Cancels a booking, computes the refund and promotes the waitlist. Send {"passenger_ids": [12, 13]} to cancel only those passengers. Requires a token. 

{"pnr": "4021887731", "cancelled": true, "refund": {"percent": 75, "amount": 1767}}

POST /api/reschedule/<pnr>

Move a confirmed booking to a new date or leg. A change fee applies. Requires a token.

{"date": "2026-11-18", "from_seq": 1, "to_seq": 4}

Response: {"pnr": "4021887731", "fee": 168, "new_date": "2026-11-18"}
